## Purpose

允许用户通过公开 GitHub 仓库中的具体插件目录地址，将所选插件按需下载并安装到 Leap 本地受管目录。在一个仓库维护多个插件的前提下，保证传输范围、内容一致性、来源确认和已有插件的数据安全。

## ADDED Requirements

### Requirement: 远程目录安装入口

Leap SHALL 在设置的插件安装入口提供远程地址安装，并继续支持本地目录安装。远程安装 MUST 接受公开 GitHub 仓库的具体插件目录 HTTPS 链接，包含仓库、分支或标签或完整提交标识，以及非空目录路径。Leap MUST 拒绝不支持的地址并显示可操作的原因。

#### Scenario: 输入具体插件目录地址
- **WHEN** 用户提交可访问的公开 GitHub 插件目录链接
- **THEN** Leap SHALL 定位该目录并开始准备候选插件，无需用户先手动下载文件

#### Scenario: 输入仓库首页或单文件地址
- **WHEN** 用户提交仓库首页或单文件链接
- **THEN** Leap SHALL 提示提供具体插件目录链接，并且不开始下载仓库文件

#### Scenario: 输入不支持或危险的地址
- **WHEN** 地址不是 GitHub HTTPS 目录链接，包含凭据或具有非法路径
- **THEN** Leap SHALL 拒绝该地址并显示原因

#### Scenario: 保留本地目录安装
- **WHEN** 用户选择从本地目录安装
- **THEN** Leap SHALL 保留既有目录选择、清单检查、信任确认和安装行为

### Requirement: 单仓库多插件按需下载

Leap SHALL 支持同一仓库中独立存放的多个自包含插件。一次安装 MUST 仅下载所选插件目录及其子目录内的文件内容，保留目录结构和必要资源，不读取其他插件文件正文。Leap MUST NOT 下载完整仓库归档、完整克隆仓库，或在失败时回退为全仓下载。

#### Scenario: 只安装仓库中的一个插件
- **WHEN** 仓库同时包含插件 A 和 B，而用户提交插件 A 的目录地址
- **THEN** Leap SHALL 只下载 A 的目录文件，不请求 B 的文件正文，也不请求全仓归档

#### Scenario: 插件包含嵌套资源和隐藏文件
- **WHEN** 所选目录包含子目录资源、自带依赖或隐藏的常规文件
- **THEN** Leap SHALL 下载这些目录内文件并保留相对结构，不因仅分析入口而遗漏资源

#### Scenario: 插件依赖兄弟目录
- **WHEN** 插件清单的入口或资源指向所选插件目录之外
- **THEN** Leap SHALL 拒绝安装，不扩大下载范围获取其他插件或公共目录

### Requirement: 下载内容固定到同一提交

Leap MUST 在下载前确定实际提交，并使用该提交获取目录信息与全部插件文件。安装来源记录 MUST 保留实际提交，以便追溯所安装的内容。

#### Scenario: 下载期间分支发生更新
- **WHEN** 用户提交分支目录链接，且远端分支在下载期间指向新提交
- **THEN** Leap SHALL 继续获取开始时确定的提交内容，不混用不同提交的文件

#### Scenario: 引用包含斜杠
- **WHEN** 用户提交的有效 GitHub 目录链接包含带斜杠的分支或标签
- **THEN** Leap SHALL 正确定位真实引用和插件路径；无法定位时显示错误，不猜测并安装其他目录

### Requirement: 完整下载与文件边界检查

Leap MUST 在目标插件完整下载并通过检查后才允许安装。远程文件路径 MUST 限于候选目录内；符号链接、子模块、Git LFS 指针、重复路径及目标文件系统名称冲突 MUST 导致失败。文件数量、目录深度、单文件体积及累计传输体积 MUST 具有有限上限，超限时显示具体原因。网络重定向 MUST 保持在允许的 GitHub HTTPS 下载主机范围内。

#### Scenario: 目录列表被截断或部分文件下载失败
- **WHEN** 远端返回不完整目录列表，或任意文件缺失、下载失败、实际大小与预期不一致
- **THEN** Leap SHALL 拒绝安装不完整候选，并清理临时内容

#### Scenario: 文件路径越界或发生名称冲突
- **WHEN** 文件条目含绝对路径、父级跳转、重复目标或本机文件系统无法区分的名称
- **THEN** Leap SHALL 拒绝候选，不覆盖候选目录之外的文件，也不静默覆盖冲突文件

#### Scenario: 目录包含不支持的特殊条目
- **WHEN** 目标目录含符号链接、子模块或 Git LFS 指针
- **THEN** Leap SHALL 提示不支持该内容并停止安装，不解析外部目标

#### Scenario: 下载超过限制
- **WHEN** 元数据或实际下载过程超过任一文件数量、深度或体积上限
- **THEN** Leap SHALL 停止下载，显示触发的限制，并清理临时文件

#### Scenario: 下载被重定向到非允许主机
- **WHEN** 网络响应要求跳转到允许范围之外的主机或非 HTTPS 地址
- **THEN** Leap SHALL 拒绝继续下载并报告错误

### Requirement: 清单验证与显式来源确认

Leap SHALL 对完整候选执行与本地插件一致的清单、入口、资源及最低宿主版本验证。每次远程安装 MUST 在写入正式受管副本前展示来源目录、实际提交、名称、版本、运行时和命令，并要求用户明确确认。远程插件 MUST NOT 通过保留的内置 ID 冒充或替换内置插件。

#### Scenario: 用户确认有效候选
- **WHEN** 下载内容通过验证且用户确认所展示的插件与来源
- **THEN** Leap SHALL 安装受管副本、保存信任及来源记录，并刷新插件列表和启动器索引

#### Scenario: 清单无效或宿主版本不足
- **WHEN** 候选缺少有效清单或入口，声明不支持的配置，或要求更高宿主版本
- **THEN** Leap SHALL 显示具体校验原因，不安装或运行候选代码

#### Scenario: 使用内置插件标识
- **WHEN** 远程候选使用 Leap 保留的内置插件 ID
- **THEN** Leap SHALL 拒绝安装，内置插件保持有效

#### Scenario: 用户拒绝确认
- **WHEN** 用户取消安装确认
- **THEN** Leap SHALL 清理候选临时内容，不新增信任记录或改变已安装插件

### Requirement: 更新替换与信任完整性

相同插件 ID 的安装 SHALL 更新已有受管副本。替换前 MUST 明确提示已有插件，来源不同 MUST 额外突出来源变化。新安装的信任 MUST 覆盖实际安装的全部常规文件，包括隐藏文件；确认后候选内容变化 MUST 阻止安装。失败时 MUST 恢复或保留旧副本及旧信任记录，继续保持原插件可用。

#### Scenario: 从相同来源更新已有插件
- **WHEN** 用户确认安装同 ID 的新候选
- **THEN** Leap SHALL 完整替换该插件并更新来源与信任记录，不影响其他插件

#### Scenario: 同 ID 来自不同来源
- **WHEN** 候选 ID 已安装，但仓库或目录来源不同，或此前只有本地来源
- **THEN** Leap SHALL 明确展示将替换的插件和来源变化，仅在用户确认后安装

#### Scenario: 正式替换过程中发生错误
- **WHEN** 受管目录提交或信任记录保存失败
- **THEN** Leap SHALL 保留或恢复此前插件与信任记录，不留下可被索引的半成品

#### Scenario: 确认内容发生变化
- **WHEN** 确认后的候选与实际暂存副本的清单或内容摘要不一致
- **THEN** Leap SHALL 拒绝该次安装并保持旧插件不变

#### Scenario: 已安装远程插件的隐藏文件被修改
- **WHEN** 已安装远程插件的隐藏常规文件被新增、修改或删除
- **THEN** Leap MUST 将该副本判定为不再符合已确认内容，不再按原信任记录加载

#### Scenario: 升级后读取旧本地插件记录
- **WHEN** 已安装本地插件的信任记录没有远程来源或新版摘要字段
- **THEN** Leap SHALL 兼容既有记录格式，不因字段缺失让此前有效插件失效，也不静默扩大信任范围

#### Scenario: 本地安装替换远程插件
- **WHEN** 用户通过本地目录安装同 ID 插件
- **THEN** Leap SHALL 按本地安装规则处理，并且不得继续把新副本标注为旧远程来源

### Requirement: 下载进度取消与错误反馈

Leap SHALL 展示解析、下载、校验和安装阶段，在已知总量时展示文件完成情况及下载大小。准备或等待确认阶段 MUST 支持取消，取消或关闭表单 MUST 停止相关下载并清理临时目录。正式提交替换阶段 MUST 防止取消打断一致性操作。错误反馈 MUST 区分地址无效、目录不可访问、网络失败、限流、下载不完整及校验失败。

#### Scenario: 用户取消正在下载的插件
- **WHEN** 用户在下载期间取消或关闭表单
- **THEN** Leap SHALL 停止该次请求并清理临时目录，不修改已有插件；迟到回调不得重新打开确认或覆盖后续操作

#### Scenario: 远端不可访问或限流
- **WHEN** 目标不存在、不可公开访问、网络失败或 GitHub 限流
- **THEN** Leap SHALL 显示相应原因，能取得限流恢复时间时予以展示，不索取首版不支持的认证凭据

### Requirement: 安装不执行远程代码或下载额外依赖

Leap MUST 只准备与安装所选插件目录，不自动执行插件代码、安装钩子、`npm`、`pip` 或其他依赖下载命令。安装确认 MUST 告知用户插件具有本机脚本权限；首次执行仍需用户触发插件命令。

#### Scenario: 插件包含依赖描述与安装脚本
- **WHEN** 下载目录包含依赖描述文件或安装脚本
- **THEN** Leap SHALL 将其作为普通文件处理，不执行脚本或自动下载目录外的依赖
