# 主搜索框检索规则

应用与插件共用 `SearchTextIndex` 和 `SearchMatchRank`。应用名称及别名、插件名称、命令标题及关键词均参与检索；Bundle ID 和命令 ID 作为标识符检索。设置页与插件内部搜索不受此规则影响。

## 输入与分词

- 原文支持精确、前缀、包含匹配，忽略大小写、声调、字符宽度及分隔符。
- 中文按汉字分音节，支持全拼、首字母以及两者混合：剪切板 → `jianqieban`、`jqb`、`jianqb`、`jqieban`。
- 英文按空白、标点、下划线、连字符和驼峰分词：Visual Studio Code → `vsc`；ClipBoard Manager → `cbm`；XMLParser → `xp`。
- 中英文可组合：微信 DevTools → `wxdt`、`weixindt`。
- 首字母与混合组合从名称开头按顺序匹配，允许前缀及末尾未完成的音节/单词，不跳字、不乱序、不跨名称或别名拼接。原文和完整转写仍支持包含匹配。
- 多音字使用 Foundation 整段转写结果；无法逐字对齐时回退到逐字转写。转写失败时保留原文检索。空检索键不参与匹配。

## 相关度

按以下顺序取每个结果的最佳等级：

1. 原文精确、前缀、包含。
2. 全拼精确、前缀、包含。
3. 首字母精确、前缀。
4. 全拼与首字母混合组合。
5. 标识符精确、前缀、包含。
6. 插件内容规则。

同等级先按最近使用时间排序，再按名称排序，应用和插件不设类型优先级。搜索最多返回 8 项。名称或标识符匹配进入交互插件时清空参数输入；仅通过内容规则进入时保留原查询。

## 索引与兼容

分词与转写在应用扫描、索引缓存加载和插件刷新阶段准备，查询不扫描文件、不启动插件、不执行转写。混合匹配以查询位置作为动态规划状态，避免展开所有组合。

应用快照版本为 5，旧版本或损坏快照自动失效，由原有后台扫描流程重建。插件清单及最近使用数据格式不变。后续更改分词或索引结构时须同步更新快照版本。索引异常沿用宿主扫描错误日志，不记录搜索正文。
