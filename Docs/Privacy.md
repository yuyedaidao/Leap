# 隐私说明

本说明分别介绍 Leap 宿主、插件和 GitHub 分发的数据处理边界。

## Leap 宿主

Leap 宿主不收集遥测，不提供账号或云同步。插件、信任记录、最近使用和应用索引缓存在本机保存。宿主提供的本机当前用户标识符也在本地保存，插件可以在调用相关 API 时读取它。

搜索与插件输入用于当前功能执行。宿主日志和插件日志可能包含调试信息，插件开发者应避免记录敏感内容。

## 检查应用更新

默认在启动时通过 HTTPS 访问 GitHub 最新正式 Release 的更新订阅；可在“通用”设置关闭。手动检查不受该开关限制。GitHub 及其附件分发服务会收到完成请求所需的 IP 地址、请求路径和客户端信息。更新模块不发送系统画像或额外遥测；用户确认后才下载安装并重启。

## 你安装的插件

插件按自身代码运行，可以使用 Node.js、Python 或 Shell 的文件和网络能力。确认信任不等于运行在文件系统沙箱内，也不代表宿主审核过其代码。

插件可在你调用时通过宿主接口访问剪贴板、文件、系统信息等能力。部分系统功能需要 macOS 授权。第三方插件可能向其服务发送数据，请先了解插件自己的说明和来源。

## 源码与下载

源代码与安装包均通过 GitHub 分发。访问仓库页面或下载安装包时，浏览器会发送完成请求所需的信息，例如 IP 地址、请求路径和浏览器信息；GitHub 可能为运行与安全记录访问日志，其行为以其隐私政策为准。

## 管理本地数据

你可以在 Leap 设置中管理插件及使用数据。清理或卸载前请自行备份重要数据；删除受管插件目录不会删除安装时选择的源目录。

本说明会随功能和分发方式调整。
