# SDK 系统 API 示例

在 Leap 设置 → 本地插件 → 安装本地插件中选择整个 `HostAPI` 目录，然后搜索“SDK 系统 API 示例”。本示例需要含系统 API 更新的 Leap 构建；清单最低版本沿用当前宿主版本，不代表旧构建已包含这些新接口。

打开独立窗口后点击按钮测试系统信息、图标、通知、剪贴板文件列表及 Finder/浏览器查询。查询窗口使用当前外部前台应用；当前为 Leap 时使用唤起插件前记录的应用。浏览器支持 Safari、Chrome、Arc。

复制会覆盖剪贴板。外部粘贴和文本输入会切回唤起前的应用，并在完成后退出插件；请先将光标置于 TextEdit 等目标应用。键盘模拟按钮只发送左方向键到当前焦点，不会隐藏窗口。没有自动执行、删除文件或模拟提交操作。

首次使用需按系统提示允许辅助功能、通知或自动化权限。权限被拒绝时界面显示错误，授权后重试。Unicode 输入是否被接受由目标应用决定；安全输入框及部分应用可能不支持。

修改示例后重新安装以更新受管副本。完整接口及数据限制见 [插件开发指南](../../../Docs/PluginDevelopment.md)。
