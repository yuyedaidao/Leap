# 数字枚举

JavaScript 原生交互列表插件，要求 Leap 1.2.0 或以上，无需安装额外运行时。

在 Leap 设置 → 本地插件 → 安装本地插件中选择本目录。然后搜索“数字枚举”或 `number`，按 Enter 进入，在顶部输入框输入非负整数。

插件计算各位数字之和，再对 10 取余，以余数作为列表长度：

| 输入 | 数字和 | 余数 | 列表 |
| --- | --- | --- | --- |
| `123` | 6 | 6 | 标题 0 至标题 5 |
| `9` | 9 | 9 | 标题 0 至标题 8 |
| `19` | 10 | 0 | 空列表 |
| `0012` | 3 | 3 | 标题 0 至标题 2 |

允许首尾空白、前导零和最多 1000 位数字；空输入与余数为 0 时均返回空列表。负数、小数及其他字符会显示中文错误提示，重新输入合法数字即可恢复。

输入变化时列表实时更新，上下键选择，Enter 显示“已选择：标题 N”，Escape 返回搜索。顶部沿用宿主输入栏、插件信息和设置按钮，不使用网页界面。

脚本使用宿主注入的 `leap.onInputChange` 和 `leap.onSelect`，无需处理通信协议；会话内复用 Node.js 进程，退出即释放。修改源文件后需重新安装更新受管副本。

在仓库根目录运行测试：`node --test Tests/NumberEnumeration/*.test.js`。
