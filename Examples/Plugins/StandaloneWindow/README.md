# 独立窗口示例

适用于 Leap 1.2.0，以本地网页展示独立窗口，无需额外依赖。

## 安装与使用

1. 打开 Leap 设置 → 本地插件 → 安装本地插件，选择本示例的整个 `StandaloneWindow` 目录。
2. 确认安装后，在启动器搜索“独立窗口示例”并执行。
3. 点击“调用脚本”，页面显示脚本返回的问候文字；失败时显示错误，按钮恢复可用。
4. 拖动窗口边缘调整大小；点击系统窗口关闭按钮或按 Escape 关闭，返回启动器。
5. 再次打开恢复清单中的 800 × 600 默认尺寸；可用屏幕不足时宿主会裁剪尺寸。

安装运行的是受管副本。修改源文件后，重新安装本目录以更新插件。

## 为什么是独立窗口

清单声明 `webEntry`，命令省略 `mode`、`presentation`、`input`，宿主因此使用现有的独立窗口路由。声明 `mode: "interactive"` 和 `presentation: "web"` 则使用内嵌网页。

`webWindow` 的单位是 macOS 逻辑点，独立窗口宽高为网页内容尺寸，不包含系统标题栏；内嵌网页的高度包含宿主操作栏。最小尺寸为 400 × 300；内嵌网页宽度跟随启动器，只有独立窗口使用清单宽度。

网页通过 `window.leap.invoke` 调用入口脚本，脚本使用宿主注入的 `leap` 并通过 `leap.log` 记录调用。当前网页导航仅允许插件目录内的本地文件，此示例不加载远程网站。
